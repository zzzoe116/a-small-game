# 一箭又一箭（OneArrowAgain）

## 项目简介

《一箭又一箭》是一款基于 Python + Pygame 开发的单格箭头益智解谜游戏。

玩家需要观察棋盘中箭头的方向以及前方是否存在其他箭头阻挡，并按照正确的顺序点击箭头，使所有箭头成功飞出棋盘。

游戏共设置 5 个关卡（满格箭头配置），随着关卡推进，箭头数量逐渐增加，难度也会逐渐提升。游戏包含完整的开始、通关、失败和全部通关结算界面。

## 游戏操作说明
- 使用鼠标点击棋盘中的箭头；
- 如果箭头前方没有其他箭头阻挡，则箭头会飞出棋盘并消失，同时播放点击音效；
- 如果箭头前方存在阻挡，则本次操作失败并扣除一次生命值（失误次数），界面会有明显的抖动、变红和错误音效反馈；
- 每关共有 3 次失误机会，失误次数耗尽则挑战失败；
- 清空当前关卡所有箭头即可通关，通关后自动进入下一关；
- 游戏界面提供“重新开始”按钮，可随时恢复当前关卡的初始状态；
- “返回主菜单”可以返回游戏开始界面。
## 主要功能
- 四方向箭头路径检测（上下左右）；
- 5 个满格关卡设计（保证每个格子都有箭头，且经过人工推演确保有解）；
- 箭头飞出动画与透明度渐变；
- 错误碰撞与抖动、变色反馈；
- 生命值（失误次数）系统与心形 UI 展示；
- 关卡计时；
- 胜利、失败和全部通关结算界面；
- 多关卡切换；
- 主菜单与游戏内双背景图片展示；
- 背景音乐（BGM）循环播放；
- 游戏全程中文界面，运行流畅。

## 开发过程与 AIGC 协作说明
- 本项目在开发过程中使用了 AIGC 工具（如 DeepSeek）进行辅助，具体协作过程包括：
- 环境搭建与报错排查：借助 AIGC 解决了 Pygame 无法导入（ModuleNotFoundError）、VS Code 中 Pylance 误报（未定义 print/int）、以及 Pygame 字体加载报错（TypeError: expected str, bytes or os.PathLike object）等问题。最终通过改用 pygame.font.Font 直接加载系统字体（如 msyh.ttc）解决。
- 界面与音效集成：参考 AIGC 的建议，实现了图片资源的加载、缩放与透明度叠加；解决了音频文件因扩展名隐藏导致的“找不到文件”问题，并实现了 BGM 循环播放与按键音效触发。
- 关卡设计与逻辑优化：在 AIGC 的辅助下，设计了 5 个满格（每格都有箭头）且必定有解的关卡，采用“整行/整列同向”以及“螺旋矩阵”的巧妙结构，确保游戏逻辑的严谨性与可玩性。
- 开发过程中 AI 生成的代码均经过本人理解、手动调试与优化，确保程序能够正常运行并符合设计预期。
